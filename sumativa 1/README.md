## 🚀 Cómo Ejecutar el Proyecto

Accede a la carpeta del proyecto y ejecuta:

```powershell
cd backendpetsalud
.\mvnw.cmd test-compile
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```
