| Sigla | Nivel de Logro | Descripción |
| :---: | :--- | :--- |
| **CL** | Completamente Logrado (100%) | Logro completo del manejo del indicador, se considera como el punto óptimo, de acuerdo al área evaluada, dentro del rango de competente. |
| **L** | Logrado (80%) | Logro del indicador, se observan pequeñas dificultades o errores para alcanzar el logro total y sobresaliendo de lo mínimo aceptable. |

| **NL** | No Logrado (0%) | Se observan un escaso, nulo o incorrecto logro en el manejo del indicador. |

## Rubrica de Evaluación

| N° | Criterios | Completamente Logrado (100%) | Logrado (80%) | Medianamente Logrado (60%) | Logro Insuficiente (30%) | No Logrado (0%) |
| :---: | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Analiza amenazas de seguridad del backend considerando el contexto del proyecto.**<br>*(10 puntos)* | Analiza todas las amenazas relevantes con justificación técnica completa y contextualizada.<br>*(10 puntos)* | Analiza la mayoría de las amenazas con justificación adecuada y pocas omisiones.<br>*(8 puntos)* | Analiza algunas amenazas con justificación superficial o incompleta.<br>*(6 puntos)* | Analiza escasamente las amenazas, sin conexión clara con el contexto.<br>*(3 puntos)* | No analiza amenazas de seguridad.<br>*(0 puntos)* |
| **2** | **Configura el framework de seguridad integrando autenticación y autorización según los requerimientos.**<br>*(20 puntos)* | Configura completamente el framework, integrando JWT, roles y control de acceso funcional.<br>*(20 puntos)* | Configura correctamente con omisiones menores en detalles no críticos.<br>*(16 puntos)* | Configura parcialmente el framework, con errores que afectan el funcionamiento.<br>*(12 puntos)* | Configura con errores significativos que comprometen la funcionalidad.<br>*(6 puntos)* | No configura el framework de seguridad.<br>*(0 puntos)* |
| **3** | **Implementa la autenticación utilizando JWT siguiendo buenas prácticas.**<br>*(15 puntos)* | Implementa correctamente JWT: generación, validación y seguridad del token.<br>*(15 puntos)* | Implementa JWT con pequeños errores que no afectan la autenticación.<br>*(12 puntos)* | Implementa JWT con fallas que afectan la validación o seguridad.<br>*(9 puntos)* | Implementa JWT con errores graves que comprometen el sistema.<br>*(4.5 puntos)* | No implementa autenticación con JWT.<br>*(0 puntos)* |
| **4** | **Asigna roles y permisos a los endpoints según los perfiles definidos.**<br>*(15 puntos)* | Asigna roles y permisos a todos los endpoints según requerimientos y sin errores.<br>*(15 puntos)* | Asigna roles y permisos con omisiones menores.<br>*(12 puntos)* | Asigna permisos parcialmente, dejando múltiples endpoints sin protección.<br>*(9 puntos)* | Asigna permisos de forma incorrecta o inconsistente.<br>*(4.5 puntos)* | No asigna roles ni permisos.<br>*(0 puntos)* |
| **5** | **Prueba la protección contra amenazas comunes documentando los resultados.**<br>*(15 puntos)* | Prueba exhaustivamente la protección contra XSS, CSRF, y SQL Injection, documentando resultados completos.<br>*(15 puntos)* | Prueba las principales amenazas y documenta con algunas omisiones menores.<br>*(12 puntos)* | Prueba parcialmente sin detallar los resultados adecuadamente.<br>*(9 puntos)* | Prueba con documentación deficiente o resultados poco claros.<br>*(4.5 puntos)* | No realiza pruebas de seguridad ni documenta resultados.<br>*(0 puntos)* |
| **6** | **Publica el código en GitHub con estructura clara y documentación técnica.**<br>*(10 puntos)* | Sube el código completo a un repositorio bien estructurado y documentado.<br>*(10 puntos)* | Sube el código con documentación adecuada y ligeros errores en la estructura.<br>*(8 puntos)* | Sube el código parcialmente, con documentación limitada.<br>*(6 puntos)* | Sube el código de forma incompleta o sin documentación suficiente.<br>*(3 puntos)* | No sube el código a GitHub o no lo documenta.<br>*(0 puntos)* |
| **7** | **Elabora un informe técnico que detalle el análisis, configuración e implementación.**<br>*(15 puntos)* | Elabora un informe completo y técnico con análisis, pasos de configuración y justificaciones.<br>*(15 puntos)* | Elabora un informe claro con omisiones menores.<br>*(12 puntos)* | Elabora un informe básico con faltantes relevantes.<br>*(9 puntos)* | Elabora un informe incompleto o mal estructurado.<br>*(4.5 puntos)* | No elabora el informe técnico.<br>*(0 puntos)* |
